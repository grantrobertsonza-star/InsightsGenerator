# Independent numerical traceability cases

cases.json contains24 semantic cases,not a numeral search. Expected classifications are independent reference judgements and product-policy questions,not application passes. Signed values and context are required. Claimed measure/group/unit/base/period must agree with cited evidence. Words and intervals count as numerical claims; operational numbers require classification. Compatible differences are proposed permissible; ratios/relative changes remain needs_review until Grant decides. A matched number does not support causality or generalisation.

The current package numberTrace implementation only checks numeral presence/rounding; these cases intentionally expose the distinction. Claude owns validator implementation. No feature, parser or semantic validator is implemented here. A validator using these fixtures cannot claim all hallucinations are detectable.
